# Esma İdeal Gıda

Esma İdeal Gıda kurumsal web sitesi — React + Vite (JavaScript).

## Çalıştırma

```bash
npm install
npm run dev
```

## Sayfalar

- `/` — Ana sayfa
- `/urunler` — Ürün kataloğu
- `/urunler/:id` — Ürün detayı
- `/hakkimizda` — Hakkımızda
- `/iletisim` — İletişim
